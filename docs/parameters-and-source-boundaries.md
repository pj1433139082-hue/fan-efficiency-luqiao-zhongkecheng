# 路桥二期参数、公式与来源边界

组合仅二期5#/6#，ID分别为PS1061-BE_GFJF_0002-C_003_0004与PS1061-BE_GFJF_0002-C_003_0001，不能按机号猜编码末尾。原效率导出仍包含一期两台，范围不混用。

目标为两台同刻实际进口风量合计，单位工况m³/min、容差±5%。历史窗、清洗F、海拔必须显式提供；本地试跑曾同意7天/F5/28m，不等于所有厂默认或厂家认证。F与目标容差是独立参数。

## 公式与清洗

效率公式唯一来源是原src/model.py。P1=101.325-H/12×0.133(kPa)，Qstd=Q×P1/101.325×293.15/(t+273.15)，r=(P1+ΔP)/P1；Wp_excel=C18/1000×Qstd/60×(r^K-1)，eta_excel=Wp_excel/P，K=0.2857，C18=354635.537746665。组合采用eta_excel，修正口径只并列核对及参与原有效性检查。

双效率20%～100%才有效；P<5kW按停机，不是P≤5。分钟运行占比至少0.5、至少2点、覆盖30秒。原物理量有效范围不认证厂家能力。eta_excel为小数，清洗前乘100转百分数。

组合原v1.1：风量后效率双端相对偏离整簇清洗，少于3点停止但非空可用；历史最值与均效来自各台保留点。组合区间与目标带相交才可行。先给逐台下限，再按容量×均效分配、超限重分配。按满足、少台数、小偏差、窄区间、高均效排序，不是边际电耗最优化。

## 旧导出文字与当前调用的区别

原src保留38.5m台儿庄模板默认值/注释，旧model-spec还有5m、P≤5kW等文字；合并程序强制显式海拔，本次28m输入不调用这些默认值。20℃“完全相同”也非精确等式，C18近似带来约0.005553%相对差异；公式及常数保持原样。

原deploy-kit README留有其他厂实验、Run及样本路径，不能作为本次组合的发布依据。新的平台适配入口与其隔离。源文件摘要见source_manifest.json，原导出文件未改。

V_P计量位置/损耗、竣工图海拔、厂家运行范围及喘振边界仍需现场证据，公开源码整理不能替代这些确认。共用时间工具对本项目现代北京时间使用UTC+8，避免标准库策略在Windows依赖额外时区包；不用于历史夏令时研究。
